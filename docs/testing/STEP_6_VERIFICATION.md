## Operational limits and remaining deployment checks

Identity and residency attestation must be performed by the committee against its own records; matching a name/mobile is never sufficient. Verification uses email, with no SMS provider. This local run does not certify an external production HTTPS/SMTP deployment; existing HTTPS-cookie/TLS deployment checks still apply. The bounded in-process mail queue can lose queued jobs on a crash, so delivery status and resend are documented recovery paths. Retention remains explicit and append-only; no existing account/Person merge or data purge is performed.

Apply additive migrations and the documented least-privilege grants before deploying the backend/UI. For local testing after pulling, use the managed stop/start commands so builds and additive upgrades run. Stop at Step 6; later features require a separate request.
