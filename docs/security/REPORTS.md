# Dashboard and report threat model

Assets: tenant resident contact data, occupancy history, financial balances/collection events, CSV artifacts and immutable export audit records. Actors: residents, committee members, committee administrators, accountants, platform operators and unauthenticated clients. Trust boundaries: public Angular configuration/browser memory, authenticated HTTP requests, live tenant authorization, restricted runtime SQL and downloaded spreadsheet applications.

| Abuse case                                          | Mitigation                                                                                                                                                                         |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Society/resource substitution or platform bypass    | Tenant scope derived from live session/membership; role ceilings and explicit read/export permissions; tenant foreign-reference validation; no platform financial aggregation      |
| Revoked permissions or disabled memberships         | Recheck authorization in each transaction; memory-only frontend views clear on context/session loss; templates gate live permissions                                               |
| SQL injection, unbounded scans/exports              | Strict query schemas, parameterized values, fixed source projections, allowlisted sorts/statuses, bounded pages/date spans, 5000-row export ceiling and per-user export rate limit |
| Spreadsheet formula execution                       | Quote escaping and apostrophe protection for formula/control prefixes including leading whitespace; regression tests parse exported multiline CSV                                  |
| Report total manipulation or return omission        | Shared collection/refund/reversal projection; exact SQL DECIMAL and BigInt formatting; full-filter summaries in the same transaction; reconciliation and boundary tests            |
| Private response persistence or late-context export | API/CSV no-store; worker caches static assets only; no local/session storage of reports; frontend drops late downloads after identity/context/route changes                        |
| Audit tampering or data leak through logs           | Restricted append-only audit privileges; export metadata excludes report contents/search/contact data; safe centralized errors and no reflected SQL/stack paths                    |

All text is rendered with Angular interpolation, never HTML injection. There are no report attachments, public download URLs, email/WhatsApp integrations or payment gateway changes. Downloaded CSV files are deliberately saved by the authorized user and remain their responsibility; browser memory and service-worker policies cannot revoke an already downloaded file. Report dates are documented explicitly, including the marked legacy UTC reversal-date fallback. Export size is bounded in memory; larger streaming/background exports require a separate reviewed implementation.
